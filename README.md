# Previewer — releases

Installer and update files for **Previewer** by RM Designs Studio: your paint, decals, numbers and wheel textures on the car in 3D.

**Install:** download `Previewer.Setup.exe` from the latest release and run it once.
After that the app updates itself: when a new version is out, an **UPDATE** box appears next to the version number in the app — click it and the app restarts on the new version.

This repo holds release files only.
